## What Needs to Happen

1. **Write the spec** — `ai/views/doc-viewer/specs/chunks/chunk-I-versioning-db.md`

2. **Database schema**
   - `file_versions` — file path, version number, content hash, timestamp
   - `checkpoints` — named snapshots (daily, AI-mod, file-close)
   - `undo_stack` — per-file LIFO undo history
   - `diffs` — delta between versions (text diff for md/txt, binary hash for others)

3. **FIFO policy**
   - Keep last 20 diffs per file
   - At diff 21, create a checkpoint and reset the diff chain
   - Daily checkpoint automation (cron or on first save of day)

4. **Trigger points**
   - AI modification → auto-checkpoint with reason `ai-mod`
   - File close → auto-checkpoint with reason `file-close`
   - Daily → auto-checkpoint with reason `daily`
   - Manual → user-initiated checkpoint with custom name

5. **Integration with file watcher**
   - `workspace-watcher.js` already emits `file:changed` for all modifications
   - Versioning service subscribes to `file:changed` and records versions
