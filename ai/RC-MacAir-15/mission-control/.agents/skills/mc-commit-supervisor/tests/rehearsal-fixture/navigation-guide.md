# Navigation Guide

The left tool rail selects a view. Checklist opens a custom iframe; Wiki opens
the built-in Wiki viewer. Selecting either view does not remove the other view.
Use the Checklist section to read the [Checklist Guide](../001-Checklist_Guide/PAGE.md).
