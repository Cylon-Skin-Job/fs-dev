> Context and re-entry memory, not owner approval or a complete history checkpoint.

## Current understanding

The newer plugin vision says protected packages supply implementation and templates; the server copies a template into a view folder outside System and binds it to the registered plugin. An instance can change configuration, appearance, persona and local skills without gaining new privileged executable authority. Existing fs-dev view and plugin summaries need reconciliation with this later direction and current code.
