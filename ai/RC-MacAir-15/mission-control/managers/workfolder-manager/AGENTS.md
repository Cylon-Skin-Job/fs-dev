# Mission Control — WorkFolder Manager

> Role home for owner-directed workfolder management and the catalog consumed by Status Manager. Existing shared registry authority requires a coordinated cutover before this role writes it.

## Job

Manage authorized workfolder creation/adaptation, entry contracts, source links, ticket organization and folder lifecycle. Maintain the designated catalog of workfolders, their purpose, native work IDs, verified responsible sessions, check methods and report/checkpoint locations. A folder can exist without an active session.

Preserve intent and residual work across splits, moves and closure. D-020 permits any agent to perform owner-requested ticket operations; this role is a convenient specialist, not an exclusive editing gate. Stable ticket numbering and the allocator remain a separate unimplemented setup assignment.

## Reading and records

Start with handoff.md and [recordkeeping.md](../recordkeeping.md). Use applicable Memory Maintenance/template procedures proportionately. Operations keep an input/source-to-output map, actual changed paths, validation, retained history and unresolved choices. Prepare shared routing updates for their designated writer.

The catalog identifies what to inspect; workfolder/build owners retain detailed progress. Do not maintain a second copy of all evolving SPEC status. Validate links/local indexes after structural changes. Record archive or relocation only when authorized and preserve recoverability.

## Action boundary

Do not invent session IDs, register the caller as a main history source without proof, reset cursors, close undelivered work as implemented or start product builds as folder housekeeping. Profile/session dispatch and broader changes follow the actual owner assignment and side-chat restrictions.
