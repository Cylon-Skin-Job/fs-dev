## Resolved precedence and source discrepancies

1. **Chat branch point:** superseded by the owner's clarification and direct supervisor handoff. Do not branch executable integration from an assumed post-original-CHAT-04 main.
2. **Execution home:** 030 PLUG-D011 already moves plugin working captures to fs-dev. The external repository remains archive/catalog intent. This new capture adds coordination rather than repeating the import.
3. **Notifications:** archived VISION §4.15 describes an in-house service, revising older inbox-as-first-plugin examples. Do not automatically select that old milestone as the first proof.
4. **Data:** archived VISION §4.11 treats internal DB as ledger, with app data in app-owned stores, revising earlier broad own-table proposals. Current Fusion persistence/receipt ownership remains intact; any new domain-store contract still needs explicit scope.
5. **Layout and classification:** archived VISION §4.4 describes flat `System/plugins/<id>` and derived categories, while fs-dev 030/032 retain category paths and broader lists. These are design discrepancies to reconcile, not authority to implement either layout merely because a file is newer.
6. **Content and capability:** archived VISION §4.13–14 distinguishes workspace configuration and editable view instances from privileged plugin definitions. Older blanket consent/hash wording must be checked against that distinction before grammar is frozen.
7. **Skills and activation:** view-as-cwd was a proposal, not proven harness behavior. Skill install unit and collision rules need reconciliation; changes must respect current chat activation and closed child-environment ownership.
8. **Consent and rescanning:** the archive identifies tracked System/state, incomplete hash coverage and an undefined rescan trigger. Carry these into contract design; no store location or approval ceremony is chosen by this capture.
9. **Provenance:** 032 separates buildable authorization/local facts from gated canonical publication. Its September 15 list of gates is a dated design input; recheck the provenance source before claiming which gates remain open today.
