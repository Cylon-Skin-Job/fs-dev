## Exact supersessions

D05 supersedes the older target that installed view instances must live inside System/Views. That path remains an observed current implementation until product migration occurs. D04 supersedes a thin-instance-only interpretation. D04–D06 supersede the old System Manager article's blanket implication that every view persona/skill/workflow edit requires privileged System modification. They do not grant unrestricted process execution or make all workspace content trusted. Do not rewrite protected-plugin authority, System database ownership, stable identities, state services, or immutable group binding merely because folder placement changes.

Existing AGENTS.md accurately describes the current path and stays unchanged. Code Standards' requirement to ship approved product replacements does not authorize implementing a product migration inside this documentation-only SPEC. No current-path examples may be replaced with invented future exact paths.
