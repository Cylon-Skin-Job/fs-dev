# Bulletin

> Volatile coordination for focused work in this capture. Bulletin entries are advisory and cannot create product authority, owner decisions, roadmap or SPEC scope, or implementation permission.

## Purpose

Use this file only when another chat could otherwise duplicate work, collide with an active assignment, remain blocked, or proceed with materially wrong context.

## Protocol

- Use stable `B-NNN` records.
- Record type, status, owner/chat, exact target, source, summary, bounded next action, and outcome.
- Allowed coordination states are `open`, `claimed`, `blocked`, `resolved`, and `superseded`.
- Add attributed responses rather than rewriting another chat's entry.
- Do not log routine progress or use this file to store intent, decisions, issues, proposals, or implementation direction.
