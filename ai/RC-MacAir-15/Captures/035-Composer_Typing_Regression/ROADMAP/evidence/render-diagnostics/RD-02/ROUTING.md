RD-02 routing decision before edits

The existing chat-turn:diagnostic:get handler retrieves one stored redacted terminal error report by turn and diagnostic ID. It cannot subscribe to a running or subsequent native event stream and must preserve its report-only semantics. Add chat-turn:diagnostic:subscribe/unsubscribe/stream in that family, through client-message-router and a focused connection-owned handler, backed by a passive runtime diagnostic observation registry. No persistence or UEB publication. OpenCode copies parser events before its existing translator; generic runtime envelopes retain exact workspace/root/epoch/thread/turn/drain ownership. Owner-approved RD-NATIVE-1 permits only opaque opt-in payloads. Existing native and Side Chat tab adapters retain ownership; diagnostics composes after both with runtime-only placement.
