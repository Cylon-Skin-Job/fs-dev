**Library** is a bundled `library-viewer` template that describes a user-selected folder in the workspace repository. It is not one of the five views chosen by the current New Workspace profile. The manifest names a possible content source; it does not itself choose a particular folder for an installed workspace.

## Current status and limits

The current fixed `ContentArea` map has no Library React component. A configured panel may use the generic app/iframe path if supplied, or otherwise display the generic placeholder. This source-inspected routing does not prove a finished Library explorer, indexing service or plugin. Before a future plugin can bind a selected folder, its declaration and path/capability validation need the platform design left open in [View Configuration And Agents](../022-View_Configuration_And_Agents/PAGE.md).

See [View Architecture](../002-View_Architecture/PAGE.md) for the distinction between a view definition, instance and content root.
