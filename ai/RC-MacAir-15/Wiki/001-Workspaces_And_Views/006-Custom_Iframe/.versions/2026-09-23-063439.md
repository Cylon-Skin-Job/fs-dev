**Custom** is the current route for a user-supplied local app or page. The bundled `custom-viewer` template declares an iframe type; a configured custom panel goes through `CustomViewer`, while an instance with `app/index.html` can use the shell-managed local-app iframe path. These are present rendering branches, not a general installable plugin lifecycle.

## Current status and limits

`CustomViewer` validates locally entered URLs. Its iframe hook can attempt to restore the initial page when it can read a changed origin, but a cross-origin redirect can prevent that read; the current app does not reliably confine subframe navigation to the initial origin. Electron currently strips frame-embedding restrictions from non-shell subframe responses, so a server’s restrictive embedding headers do not necessarily stop that page from displaying in Fusion. It does not gain Electron or Node APIs merely by appearing in the view. Custom is optional in the current New Workspace profile. The approved plugin model separates protected display/capability code from editable instance settings, but its declaration and permission enforcement remain future work.

Use [Browser](../005-Browser/PAGE.md) for general web navigation. [View Configuration And Agents](../022-View_Configuration_And_Agents/PAGE.md) distinguishes safe instance edits from plugin capability changes.
