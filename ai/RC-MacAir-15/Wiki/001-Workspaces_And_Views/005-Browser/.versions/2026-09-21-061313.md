**Browser** is for navigating web pages inside the workspace shell. The bundled `browser-viewer` template declares the browser type. Current `ContentArea` routes a configured browser panel to `WebBrowser`, which keeps tab and history state in the component and renders its active page in a sandboxed iframe. The URL validator accepts ordinary web addresses; the address bar and navigation controls belong to this view.

## Current status and limits

This is an iframe surface, not a full independent browser process. Cross-origin documents cannot be inspected freely from the parent page, and sites may refuse iframe embedding. The template is optional for the current five-view New Workspace profile; template availability alone does not install a view in every workspace. A future view plugin would own display and capability behavior; the current renderer still chooses its component by configuration and fixed routing.

Use [Custom Iframe](../006-Custom_Iframe/PAGE.md) for a local embedded app. [View Architecture](../002-View_Architecture/PAGE.md) explains the definition/instance boundary.
