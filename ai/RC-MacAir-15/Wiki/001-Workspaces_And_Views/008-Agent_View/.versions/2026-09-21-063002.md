**Agents** displays agents indexed in the workspace's `Agents` content area. The bundled `agents-viewer` template is selected by the current New Workspace profile. `AgentTiles` reads `settings/agents.json` through the panel data hook, then shows agent cards and Markdown details for a selected agent.

## Current status and limits

This is a mounted React surface, but its visible Runs and Settings detail panes still contain placeholder text. A card in this view is not proof that an agent process launched or that every workflow is executable. It is also distinct from the approved future **persona and skills inside each view instance**: those resources tailor an individual view, whereas this view is a workspace surface for browsing agent entries. Current harness context loading for view-local resources remains unfinished.

Read [View Configuration And Agents](../022-View_Configuration_And_Agents/PAGE.md) for that target and gap, and [View Architecture](../002-View_Architecture/PAGE.md) for mounted views versus instances.
