Wired the workspace watcher to emit `file:changed` on the Universal Event Bus so any domain can subscribe without owning a watcher instance.

### What shipped

- `lib/watch/workspace-watcher.js` emits `file:changed` for every add/modify/delete/rename in the workspace
- Rename detection: delete + create in the same directory within 2s window → single `rename` event (emitted as delete + create pair on UEB)
- Pluggable filter system (`addFilter`) preserved for domain-specific side effects
- Fixed chokidar `ignored` option to use a function (absolute → relative path) so `node_modules` and other excludes actually match

### Files created / modified

- `lib/watch/workspace-watcher.js` (new — replaces lib/watcher/index.js)
- `lib/watch/workspace-context.js` (new — context builder for filter system)
