Design and create a set of onboarding tickets that ship inside the app (pre-loaded in the Issues viewer) to guide first-time users through setup.

### Ticket List

1. **Cloud Backup Setup**
   - Detect or ask which cloud provider: iCloud / Google Drive / Microsoft OneDrive / Other / Skip
   - Confirm OS version (macOS minimum, future Windows/Linux)
   - Walk user through provider-specific setup steps
   - Offer to create `Fusion Studio/` folder inside the chosen cloud folder
   - Create symlink from cloud folder to local System Files root as `fusion-studio-cloud-sync`
   - Document the symlink relationship so user understands what's mirrored vs local

2. **System Files Initialization** (depends on cloud backup choice)
   - Copy bundled seed templates to `~/Fusion Studio/System Files/`
   - If cloud backup chosen, set up sync relationship
   - Show user what's been created and where

3. **First Workspace Setup**
   - Prompt user to choose or create a first workspace folder
   - Explain workspace vs System Files distinction
   - Optionally clone a starter template

### Open Questions

- Should onboarding tickets auto-dismiss as completed, or persist for reference?
- Should they be hardcoded in the app bundle, or generated on first run?
- What happens if user skips cloud backup — do we create local-only tickets?
- Should the symlink name `fusion-studio-cloud-sync` be user-customizable?
