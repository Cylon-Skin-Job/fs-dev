Design the workspace creation experience, default V2 folder structure, and AI-guided onboarding for view customization.

---

## Workspace Creation Modal

Two options are presented:

- **Create from Project Folder**: user selects an existing project folder; Fusion Studio creates `ai/<machine>/` inside it and preserves existing files.
- **Create New Workspace**: user enters a workspace name; Fusion Studio creates the project folder and copies the canonical V2 template.

---

## Default V2 Workspace Structure

Every workspace uses the machine-scoped V2 layout:

```text
{workspace}/
└── ai/
    └── <machine>/
        ├── Views/
        │   ├── 001-doc-viewer/
        │   │   ├── manifest.md
        │   │   ├── content.json
        │   │   ├── styles/
        │   │   │   ├── icon.md
        │   │   │   ├── layout.css
        │   │   │   └── layout.json
        │   │   └── state/
        │   ├── 002-file-viewer/
        │   ├── 003-wiki-viewer/
        │   ├── 004-issues-viewer/
        │   └── 005-agents-viewer/
        ├── Wiki/
        ├── Captures/
        ├── Issues/
        ├── Agents/
        ├── System/
        │   ├── config/
        │   ├── state/
        │   └── styles/
        └── Data/
            ├── Chatlogs/
            ├── Runs/
            └── Screenshots/
```

`Views/` folder order is the source of truth for left sidebar ordering. Each view declares its nav icon in `styles/icon.md`; there is no `views.json` icon registry.

---

## Default Views

| View | Folder suffix | Purpose |
|------|---------------|---------|
| Captures | `doc-viewer` | Captures, specs, notes, and document-oriented project material |
| Files | `file-viewer` | Browse project files |
| Wiki | `wiki-viewer` | Documentation |
| Issues | `issues-viewer` | Ticket board |
| Agents | `agents-viewer` | Skills, triggers, background workers, and agent configuration |

Browser/custom iframe views can be added, but iframes are for user-created HTML content and browser-like surfaces. Built-in views remain React views.

---

## Template Library

The canonical source is `System_Manager/ai-template/`. New workspaces copy from that template and omit unselected view folders. View templates live under `System_Manager/ai-template/templates/view-templates/`.

---

## AI Onboarding Prompt

After workspace creation, AI can offer help through the Issues/Wiki/Chat surfaces:

> "Welcome to your new workspace. I set up Captures, Files, Wiki, Issues, and Agents. What else do you need?"

The AI can offer to add custom views, explain the V2 folder structure, or help configure automations.
