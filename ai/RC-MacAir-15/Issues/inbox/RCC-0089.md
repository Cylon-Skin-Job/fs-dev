## What Needs to Happen

1. **Write the spec** — `ai/<machine>/Views/*-doc-viewer/specs/chunks/chunk-H-view-discovery-add.md`

2. **Context menu integration**
   - Right-click on empty area of panel container → context menu
   - Menu populated from discovered templates in `System Files/views/`
   - Templates include: wiki, doc-viewer, file-viewer, issues, calendar, tools, etc.

3. **Auto-numbering**
   - Scan workspace `ai/<machine>/Views/` for existing IDs of same type
   - Next ID: `wiki-viewer-01`, `wiki-viewer-02`, etc.
   - Prevent collisions with manually created folders

4. **Template instantiation**
   - Call `instantiateTemplate(templateId, workspacePath)` (from Chunk G)
   - Copy template files + index.json + content.json + settings/
   - Refresh panel discovery after add

5. **Template metadata**
   - Each template in `System Files/views/{type}/` has `index.json` with name, icon, description
   - Used for menu labels and icons
