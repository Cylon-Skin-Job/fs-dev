# Skills

AI skill definitions that ship with Fusion Studio.

Each skill is a self-contained folder with:
- `skill.json` — identity, description, available tools
- `prompt.md` — system prompt fragment injected into AI context
- `tools/*.json` — tool schemas (name, description, parameters)

Skills are discoverable by both Fusion Studio and linked CLI tools (Claude, Kimi, Codex, Anti-Gravity).
