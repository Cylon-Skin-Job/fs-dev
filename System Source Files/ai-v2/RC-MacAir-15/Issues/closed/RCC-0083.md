### Bug fixes caught during testing

Four server files missed in the original spec sweep (caught via grep audit after testing):
- `lib/theme/themes-service.js` — 2 paths updated
- `lib/ws/workspace-broadcaster.js` — 1 path updated
- `server.js` lines 201 + 516 — `/api/view-config` globalCss path and `workspace:init` CSS pre-read path

Root cause of force-reload CSS bug: `workspace:init` pre-read from old path returned empty strings; client called `injectWorkspaceStyles([])` which stripped all CSS. Fixed by correcting line 516 to `ai/system/styles`.
