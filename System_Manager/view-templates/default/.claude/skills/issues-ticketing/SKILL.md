# Issues Ticketing

Use this skill when creating or managing workspace tickets.

## Guidance

- Use generated ticket ids for live tickets.
- Treat `TICKET.md` files under `.templates` as reusable sources, not live tickets.
- Capture status, affected files, affected wikis, dependencies, pass conditions, and blockers.
