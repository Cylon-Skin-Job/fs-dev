# System

Use this skill when work touches system-level tools, prompts, launchers, triggers, policies, or protected workspace files.

## Guidance

- Treat protected changes as System Manager-owned unless explicitly approved.
- Prefer request tickets and approval metadata over direct mutation.
- Keep normal workspace agents focused on reading, proposing, and generating evidence.
