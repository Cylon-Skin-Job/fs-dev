View customization covers the panels and surfaces that make workspace files, wiki pages, agents, issues, browsers, and custom applications usable inside Fusion Studio.

Views are part of the workspace model. A view may be built in, template-backed, or custom, but it should still resolve through the workspace's configuration and file structure.
