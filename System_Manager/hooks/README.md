# Hooks

Per-CLI hook configurations that ship with Fusion Studio.

Each hook config defines how to inject Fusion Studio context into a specific AI CLI:
- `claude.yaml` — Claude Code before-send hook
- `kimi.yaml` — Kimi CLI hook
- `codex.yaml` — Codex CLI hook
- `antigravity.yaml` — Anti-Gravity hook

Hook configs are symlinked into the user's CLI configuration directory during onboarding.
