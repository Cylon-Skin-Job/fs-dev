Create the canonical AI workspace template v2 and migrate Fusion Studio piece by piece to the new `ai/<user-machine>/` paradigm.

**Spec:** `docs/AI_WORKSPACE_TEMPLATE_V2_SPEC.md`

---

## What Needs to Happen

1. **Review the spec**
   - Read `docs/AI_WORKSPACE_TEMPLATE_V2_SPEC.md`.
   - Confirm the target folder model and open decisions before implementation.

2. **Audit current sources**
   - Current working `ai/` folder.
   - Existing workspace templates.
   - `System Source Files` defaults.
   - Prototype folder: `System Source Files/ai-v2/RC-MacAir-15/`.

3. **Create canonical template**
   - Build `System Source Files/ai-template/` from the agreed v2 shape.
   - Include `System`, `Views`, `Chat`, `Runs`, `Skills`, `Wiki`, `Agents`, `Issues`, `Data`, `Prompts`, `Tools`, and `Scripts`.
   - Include default setup skill, setup tickets, starter view folders, and starter layout/state files.

4. **Update workspace creation**
   - Copy `System Source Files/ai-template/` into new workspace root as `ai/`.
   - Omit views the user did not select.
   - Preserve numeric view order prefixes.

5. **Convert view discovery and ordering**
   - Make the server scan `ai/<user-machine>/Views/` for active views.
   - Convert right-click move up/down logic to rename numeric prefixes like `001-wiki-viewer`.
   - Preserve per-view `styles/` and `state/` during reorder operations.

6. **Move state to per-view folders**
   - Replace old global state assumptions with `Views/<viewer>/state/state.json`.
   - Use `Views/<viewer>/styles/layout.json` for icon, layout, rank-related display metadata, and appearance defaults.

---

## Files That Will Likely Change

- `System Source Files/ai-template/` — new canonical template
- `System Source Files/ai-v2/RC-MacAir-15/` — prototype/reference source
- Workspace creation/copy service code
- Server view registry/discovery code
- View reorder UI/server handlers
- Existing `ai/system/workspace/views.json` consumers
- Existing `ai/system/state/state.json` consumers

---

## Smoke Tests

- [ ] New workspace creation copies `ai-template` to `<project-root>/ai/`.
- [ ] Unselected views are omitted from copied workspace template.
- [ ] Server view list is derived from `Views/001-name-viewer` folder order.
- [ ] Moving a view up/down renames numeric prefixes safely.
- [ ] Per-view state persists in `Views/<viewer>/state/state.json`.
- [ ] Per-view layout/icon metadata loads from `Views/<viewer>/styles/layout.json`.
- [ ] Setup skill and setup tickets are present in new workspaces.
