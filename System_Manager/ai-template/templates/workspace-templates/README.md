# Workspace Templates

Workspace templates define selected views and starter content for a workspace type.

- `new/` is the default new workspace profile and selects only `file-viewer`, `wiki-viewer`, `issues-viewer`, and `agents-viewer`.
- `startup/` contains shipped startup workspace profiles such as Fusion Home, Media Studio, Invoicing and Expenses, and System Source Files.

View shells are copied from `templates/view-templates/`. Template-specific starter data belongs in the workspace template's top-level data folders.
